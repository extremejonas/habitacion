Armar el candado

Elegí tu clave y se genera index.html, la página ya encriptada, lista para subir a GitHub. La clave no se guarda ni se envía a ningún lado.

  1. Se descarga index.html.
  2. En GitHub: Add file → Upload files, arrastrá ese archivo y Commit changes.
  3. Esperá 1 o 2 minutos y abrí la dirección del sitio.

Si cambiás la clave, repetís este paso. Si te olvidás de la clave no hay forma de recuperarla: hay que generar otra.
